Vue 核心概念笔记（一句话版）

一、Vue 是怎么跑起来的？

  • main.ts是整个应用的 入口
  • createApp(App).mount('#app')相当于 Java 的 new Application().run()
  • 从这开始，Vue 接管页面

二、组件到底是什么？

  • .vue文件 = 一个 组件
  • 组件 ≈ Java 类
  • export default {}= 告诉 Vue：这是一个组件
  • <HelloWorld />= 使用这个组件（new 一个实例）

五、什么是响应式？（最重要）

  • 响应式 = 数据变 → 页面自动变
  • ref()就是让数据“能被 Vue 监听”
  • 普通变量变了： ❌ Vue 不知道 ❌ 页面不更新

📌 Java 类比：

  • 响应式 ≈ 观察者模式

六、v-model 和响应式的关系

  • v-model只是语法糖
  • 本质是： 绑定值 监听输入 改响应式数据
  • 没有响应式，v-model 没用

七、setup() 是干嘛的？

  • setup()= 组件构造器
  • 每次创建组件都会执行一次
  • 在里面初始化响应式数据

八、import / export 怎么理解？

  • export= 对外暴露（public）
  • 没写 = 内部私有（private）
  • { }= 具名导出
  • export default= 主出口

📌 Java 类比：

  • {}→ import static
  • default→ 主类
